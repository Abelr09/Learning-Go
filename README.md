# Learning Go

Repositorio dedicado al aprendizaje y práctica del lenguaje de programación Go.

## Estructura del Proyecto

El proyecto está organizado en carpetas temáticas que cubren diferentes aspectos del lenguaje:

- **basics/** - Conceptos fundamentales (variables, tipos de datos, operadores)
- **control-flow/** - Estructuras de control (if/else, switch, bucles for)
- **functions/** - Funciones, parámetros, valores de retorno y closures
- **data-structures/** - Arrays, slices, maps y structs
- **interfaces/** - Interfaces y polimorfismo
- **concurrency/** - Goroutines, channels y sync
- **error-handling/** - Manejo de errores y panic/recover
- **testing/** - Tests unitarios y benchmarks
- **projects/** - Proyectos prácticos para aplicar conceptos aprendidos

## Requisitos

- Go 1.21 o superior
- Editor de código (VS Code recomendado con extensión Go)

## Cómo Ejecutar los Ejemplos

Cada carpeta contiene ejemplos independientes. Para ejecutar cualquier ejemplo:

```bash
cd basics
go run main.go
